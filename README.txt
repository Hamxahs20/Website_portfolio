HAMZAH ALSALMAN — PORTFOLIO WEBSITE
===================================

QUICK START
1. Unzip this folder.
2. Open index.html in Chrome, Safari, Firefox, or Edge.
3. Use Work, Archive, Beyond Design, and About to browse the site.
4. To publish, upload the entire folder to Netlify, GitHub Pages, or another static hosting provider.
   Keep the assets/ folder beside index.html.

CONTENTS
- 4 featured case studies: Sukoon, The Silver Screen, Docks on the Go, Edible Dialogue.
- 6 earlier engineering/design projects: Troughineers, EMT Lifting Straps,
  Parkinson's Gloves, RaceCycle, Mindful Lantern, CAD Models.
- 6 initiatives: NASNA, Georgia Tech leadership, Saudi Student Association,
  SM / MiSK Fellowship, Muslim Creative Society, Human Development & Startups.
- About, contact, project videos and original PDF portfolio.

CONTENT NOTES
- All visual assets are assembled from the uploaded portfolio and images.
- Existing team-project results and concepts are shown as originally documented;
  speculative proposals are labelled and should not be represented as deployed products.
- Older screenshots and compressed source imagery vary in sharpness.
- Check all collaborators' credits, any publication permissions, and contact details before publishing.
- Mobile uses a responsive layout and animations respect reduced-motion preferences.
